# Taleem ul Quran Learning — Online Quran Academy

A modern, responsive, bilingual (English & Urdu with RTL support) online Quran learning platform built with React 19, Tailwind CSS v4, and Vite.

## ? Features

- ?? **Comprehensive Course Offerings**: Quran Reading with Tajweed, Hifz, Islamic Studies, and Sisters Special Classes.
- ?? **Full Multilingual Support**: Seamless instant switching between English (LTR) and Urdu (RTL).
- ?? **100% Mobile & Tablet Optimized**: Responsive layouts, touch-enabled course slider, smooth interactive FAQ accordions.
- ?? **Integrated Free Trial Form**: Direct lead dispatching to email via Web3Forms/Formspree and WhatsApp confirmation.
- ? **Lightning Fast**: Built on Vite 6 and optimized for immediate deployment on Vercel.

## ?? Deployment to Vercel

1. Import this repository into [Vercel](https://vercel.com).
2. Framework Preset: **Vite**
3. Build Command: \
pm run build\
4. Output Directory: \dist\
5. (Optional) Set Environment Variables:
   - \VITE_CONTACT_EMAIL=extramailcom2233@gmail.com\
   - \VITE_WEB3FORMS_ACCESS_KEY=your_key_here\
