Design and build a complete, modern, professional, responsive frontend website for an online Quran academy called **“Taleem ul Quran Learning.”**

The website is for students of all ages in Pakistan and internationally. Students can learn Quran from home through personalized 1-on-1 live classes with male or female tutors.

Use the provided **Taleem ul Quran Learning logo** as the official brand logo. Do not create a different logo.

## Brand Identity

Academy Name:
**Taleem ul Quran Learning**

Tagline:
**Learn • Practice • Grow**

Design direction:

* Modern
* Professional
* Peaceful
* Trustworthy
* Educational
* Islamic but not overly traditional
* Clean and premium
* Lots of whitespace
* Soft rounded cards
* Subtle shadows
* Elegant typography
* Smooth animations
* High-quality imagery
* Avoid clutter

### Color Palette

Primary:

* Deep Islamic green
* Emerald green

Secondary:

* Soft cream
* Warm white

Accent:

* Subtle gold

Dark mode:

* Deep charcoal/green backgrounds
* Cream/white text

# GLOBAL REQUIREMENTS

Build the website as a fully responsive design.

It must work beautifully on:

* Large desktop
* Standard desktop
* Laptop
* Tablet
* Mobile phone

Do not simply shrink the desktop design on mobile. Create a proper responsive layout.

### Mobile requirements

On mobile:

* Use a hamburger navigation
* Stack sections vertically
* Convert multi-column cards into single-column or horizontal-scroll layouts where appropriate
* Make buttons full-width when necessary
* Keep typography readable
* Keep forms easy to use
* Maintain proper spacing
* Prevent horizontal scrolling
* Keep the WhatsApp floating button accessible
* Preserve the visual hierarchy
* Optimize images for smaller screens

The website must look intentionally designed for mobile, not like a desktop website squeezed into a phone.

# LANGUAGE SWITCHING

Implement the UI concept for:

**English | اردو**

English is the default.

When Urdu is selected:

* Switch entire interface to RTL
* Reverse appropriate layout directions
* Align text correctly
* Keep forms RTL
* Keep navigation RTL
* Keep cards and buttons properly aligned
* Use an appropriate Urdu-compatible font

Do not create a separate unrelated Urdu design. It should be the same website translated and directionally adapted.
